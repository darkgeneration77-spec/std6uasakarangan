Cerita

Pada hari Sabtu yang lalu, sekolah saya mengadakan Program Gotong-royong Perdana. Murid-murid dan guru berkumpul untuk mendengar taklimat sebelum aktiviti bermula.

Kumpulan saya ditugaskan membersihkan kelas. Kami menyapu lantai, mengelap meja dan menyusun kerusi dengan kemas.

Selepas itu, kami mengutip sampah serta daun-daun kering. Beberapa orang murid turut membersihkan longkang. Semua murid bekerjasama menjalankan tugas masing-masing.

Program berakhir pada tengah hari. Saya gembira kerana kawasan sekolah menjadi bersih dan ceria. Aktiviti ini mengajar saya bahawa kebersihan sekolah ialah tanggungjawab bersama.

Laporan

Laporan Program Gotong-royong di Sekolah

Sekolah saya telah mengadakan Program Gotong-royong Perdana pada hari Sabtu. Program ini disertai oleh murid-murid dan guru.

Para peserta dibahagikan kepada beberapa kumpulan. Mereka membersihkan kelas, mengutip sampah, menyusun kerusi dan membersihkan longkang.

Program tersebut berjalan lancar dan kawasan sekolah menjadi lebih bersih serta ceria. Aktiviti ini berjaya memupuk semangat bekerjasama dalam kalangan murid.

Laporan disediakan oleh,3 SEPTEMBER 2026
